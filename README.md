# История искусства Гомбриха: справочник к чтению

Сайт для медленного чтения книги Э. Гомбриха. Главная страница (`index.html`) показывает все 28 глав, готовые главы открываются отдельной страницей.

## Что где лежит
- `index.html` главная со списком глав
- `chapter-23.html`, `chapter-24.html` готовые главы 23 «Век разума» и 24 «Разрыв традиции»
- `data/` данные (список глав, содержание главы 23)
- `assets/` оформление и скрипты
- `images/ch23/`, `images/ch24/` картинки глав (имена вида `ch23_il303_hogarth_rakes-progress-8_in-bedlam_print.jpg`: глава, номер иллюстрации в книге или вид, автор, что изображено)

## Картинки
Открой `download-images.html` в браузере, нажми кнопку и получи архив `gombrich-images.zip`. Распакуй `gombrich-images.zip` в корень сайта: папки `images/ch23` и `images/ch24` создадутся сами. Если файла нет, страница сама подтянет картинку с Wikimedia Commons, так что с интернетом всё работает и без папки. Авторы и лицензии указаны на вкладке «Источники».

## Как выложить на GitHub Pages
1. Создай репозиторий на github.com и загрузи в него содержимое этой папки (кнопка Add file, Upload files).
2. Settings, затем Pages, источник Deploy from a branch, ветка main, папка root.
3. Через минуту сайт откроется по адресу `https://ТВОЁ-ИМЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

## Как добавить новую главу
1. В `data/chapters.js` у нужной главы поставь `ready:true` и `page:"chapter-NN.html"`.
2. Страницу главы и данные `data/chNN.js` собирает скрипт из исходников, поэтому новые главы лучше делать через Claude. Картинки называй по тому же правилу: `chNN_...`.

Авторские заметки и отметки «прочитала» хранятся только в браузере читателя.
